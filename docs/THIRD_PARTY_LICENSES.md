# Third-party notices

The project code is MIT. Runtime packages retain their own licenses. `THIRD_PARTY_LICENSES.txt` includes the exact installed package versions and license files collected by `node scripts/licenses.mjs`. `dependency-licenses.json` is the machine-readable summary. Player packages include the full notices file.

Core choices include React MIT, Zustand MIT, React Flow MIT, Motion MIT, Tiptap MIT, Zod MIT, Dexie Apache-2.0, JSZip MIT alternative, and Lucide ISC / Feather MIT notices. No paid Pro assets, proprietary Apple fonts, official brand icon packs or unauthorized photos are included.

Build/test tooling licenses stay in their installed npm packages; source distribution includes package-lock.json so maintainers can reproduce and inspect them. Do not label user-uploaded assets or user stories MIT without their author's choice. Brand names remain owned by their respective owners and are only unofficial template references.

## Adapted iOS web code

See licenses/ios-web and docs/IOS_REUSE_ASSESSMENT.md. Upstream code notices are appended by scripts/licenses.mjs to THIRD_PARTY_LICENSES.txt for Studio and static players. Unlicensed Mindenry/goranbyte sources and upstream images/fonts are not included.
