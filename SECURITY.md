# Security

Current version is a local development preview. Do not treat narrative passcodes as encryption. Avoid importing untrusted oversized projects. No imported scripts or raw HTML are executed by design. Supported media excludes SVG and remote URLs.

Report vulnerabilities privately using the repository's GitHub Security Advisory feature once published. Do not post private story content or credentials in public issues. There is currently no public repository/contact configured.

Runtime dependency audit, import-validation checks and automated smoke tests are part of development, not a guarantee of comprehensive security review. ZIP decompression hardening, richer schema constraints and resource-limit fuzzing remain useful follow-up work.
