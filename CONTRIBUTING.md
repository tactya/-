# Contributor guide

Use Node 22.12+, npm ci. Read docs/ARCHITECTURE.md. Fork-first is recommended, not mandatory under MIT. Keep changes focused and preserve local drafts and user files. Test pure story changes with Vitest and user workflows with Playwright. Run typecheck, lint, tests and production build before proposing a PR.

For schema changes, document migration and save-version behavior. All newly added assets require a license/source record. Do not include third-party trademark artwork as MIT assets. Never add hidden GitHub account actions or telemetry.
